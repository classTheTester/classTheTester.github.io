      ArtLingo - AI-based Art Critic

      Artlingo is an AI-powered art feedback platform that analyzes uploaded or hand-drawn artwork to evaluate line quality, color harmony, and value distribution in real time. The system uses a dual-stream EfficientNet-B0 architecture to process both local image patches and global image context, combining supervised learning with computer vision techniques such as K-Means clustering, Canny edge detection, and grayscale value analysis. A custom artist-annotation pipeline with Gaussian-smoothed heatmaps and a hit@5 evaluation metric was implemented to improve training quality and prediction relevance.
